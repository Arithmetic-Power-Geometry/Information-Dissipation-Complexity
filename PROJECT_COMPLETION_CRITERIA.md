# Completion criteria for the Information-Dissipation Complexity project

## Ideal completion

The strongest mathematical closure would be:
[
N_{max}(1)=0,quad N_{max}(2)=1,quad N_{max}(3)=3,quad N_{max}(4)=5,
]
with the four-level upper bound proved analytically or by a fully rigorous finite interval certificate, together with the existing exact five-root witness.

## Strong publishable completion even if the exact d=4 problem remains open

The paper is ready to freeze when all of the following hold:

1. Exact power-sum/Renyi/escort identities are presented with classical attribution.
2. The new transient-amplification and transition-complexity problem is clearly defined.
3. The complete two-level classification is proved.
4. The sharp three-level theorem (N_{max}(3)=3) and the lambda=4 bifurcation/phase diagram are proved.
5. The general pair/triple cumulant decomposition is proved.
6. The four-level finite chamber certificate and global upper bound 11 are independently reproducible.
7. The exact five-root lower-bound construction is independently interval-certified.
8. Exploratory searches are not stated as theorems.
9. Novelty/prior-art audit is updated immediately before submission.
10. Code, exact witnesses, chamber tables, and certificates reproduce from a clean checkout.

At that point the mathematically honest frontier
[
5le N_{max}(4)le11
]
is itself a legitimate open problem generated by the theory rather than an incompleteness in the paper.

## Recommended stopping rule

Do not let the exact four-level problem delay the manuscript indefinitely. Give the (N_{max}(4)=5) obstruction program one focused final phase: uniform tail + boundary reductions + compact interval feasibility. If that phase does not close the gap, freeze the theorem at (5le N_{max}(4)le11), state exact (N_{max}(4)) as an open problem, complete independent reproducibility/novelty checks, and write the paper.
